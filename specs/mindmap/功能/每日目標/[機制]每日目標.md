# 範圍

每日目標是使用者為時間軸上的一天設定的：專注目標（分鐘）、分心上限（分鐘），以及哪些分類算專注、哪些算分心。本機制定義目標的保存、沒有設定時沿用什麼、如何與實際的卡片對照，以及每天何時主動詢問。

引用本機制的功能：[設定每日目標](<[功能]設定每日目標.md>)、[查看每日目標進度](<[功能]查看每日目標進度.md>)；AI agent 設定目標見[透過 Agent 設定每日目標](<../Agent存取/[功能]透過Agent設定每日目標.md>)。

# 目標的組成

| 內容 | 說明 |
|---|---|
| 那一天 | 時間軸上的一天（以早上 4:00 為界），每天最多一份目標 |
| 專注目標 | 分鐘數 |
| 分心上限 | 分鐘數 |
| 專注分類、分心分類 | 設定當下的分類快照（分類身分、名稱、顏色、順序） |
| 是否略過 | 使用者這一天選擇略過、不設定目標 |

# 預設目標

從未設定過任何目標時，採用預設：專注目標 270 分鐘、分心上限 120 分鐘；名稱為 Distraction（或 Distractions）的分類算分心，其餘非系統、非 Idle 分類算專注。

# 沿用上一次的目標

1. 某一天沒有自己的目標時，沿用「這一天或之前最近一次保存的目標」（含略過的那一份的數值與分類），沒有任何保存過的目標時用預設目標；沿用的目標不算略過。
2. 沿用或顯示時，目標中的分類快照會依分類身分對應到目前的分類（找不到身分時依名稱，不分大小寫），取用目前的名稱與顏色；兩者都找不到時保留快照原樣。已保存的目標本身不被改寫。

# 目標與實際的對照

1. 實際專注時間：這一天的卡片中，分類屬於專注分類者的時間加總。
2. 實際分心時間：這一天的卡片中，分類屬於分心分類者的時間加總。
3. 判斷卡片是否屬於某組分類：先以卡片的分類名稱找到目前的分類，再比對分類身分；找不到時直接比對快照中的名稱（不分大小寫）。System 與系統分類（Idle）不計入。

# 每天詢問目標

使用者打開時間軸時，滿足以下全部條件才主動跳出設定目標的畫面（並切到今天的日檢視）：

1. 使用者沒有關閉「每日目標彈出提示」，且這一天沒有改為顯示 Daily brief。
2. 這一天還沒有處理過（已設定或已略過就記為已處理）；這一天已經有目標時直接記為已處理。
3. 除了今天之外，時間軸上至少有 3 個不同的日子有卡片。
4. 今天之前最近幾次的回應不是連續 5 次略過（從最近一次往回數，遇到一次確認就停；沒有回應的日子不影響）。

時間軸的一天在早上 4:00 換日時，畫面自動切到新的一天。

# 實例化情境

小安第一週沒有被詢問（只有 2 天的資料）。第四天第一次打開時跳出設定畫面，預設專注 270 分鐘、分心 120 分鐘，他改成專注 300 分鐘並確認。第五天他沒有再設定，沿用專注 300 分鐘；當天卡片中 Coding 180 分鐘、Communication 60 分鐘、Distraction 50 分鐘，畫面顯示專注 240／300 分鐘、分心 50／120 分鐘。
