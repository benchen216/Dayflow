# 修正清單

規格已改寫為使用者 string 確認的預期行為；以下是程式碼目前與規格不同之處，依嚴重度排序。

## 1. 使用分析送出卡片內容與使用者輸入的文字（隱私，高）

- **規格**：[使用分析與錯誤回報](<功能/其他/[功能]使用分析與錯誤回報.md>) E-3：使用分析只送統計，不送卡片的標題、摘要、詳細說明、網站、分心片段，也不送使用者輸入的文字。
- **現況**：對卡片摘要按讚／倒讚的事件帶卡片標題、摘要、詳細說明、主要與次要網站、前三個分心片段與使用者的意見文字；刪除卡片的事件帶卡片標題；新手引導的個人目標事件帶使用者輸入的目標。送出前的清理只依欄位名稱過濾，不會移除這些內容。使用分析預設開啟。
- **可能後果**：AI 從螢幕寫出的內容（客戶名稱、專案細節、私人訊息）送到 PostHog，違反「螢幕資料不交給使用者無法掌控的地方」。
- **證據**：
    - `Dayflow/Dayflow/Views/UI/MainView/Actions.swift:320-366`（timelineFeedbackAnalyticsPayload）
    - `Dayflow/Dayflow/Views/UI/MainView/Actions.swift:58-76`（timeline_summary_feedback_submitted 的 feedback_message）
    - `Dayflow/Dayflow/Views/UI/MainView/Actions.swift:262-318`（timeline_activity_deleted 的 activity_title）
    - `Dayflow/Dayflow/Views/Onboarding/OnboardingFlow.swift:173-184`（onboarding_personal_goal 的 goal）
    - `Dayflow/Dayflow/System/AnalyticsService.swift:574-592`（sanitize 只依欄位名稱過濾）
    - `Dayflow/Dayflow/System/AnalyticsService.swift:225-236`（預設開啟）
- **修正方向**：上述事件改為只送長度、數量、分類等統計；或在送出前一律移除內容型欄位。

## 2. Agent 修改或刪除不存在／已刪除的活動仍回報成功（資料完整性，中）

- **規格**：[透過 Agent 修改或刪除活動](<功能/Agent存取/[功能]透過Agent修改或刪除活動.md>) C-1：活動必須存在且未刪除，否則回報 not_found、不做任何修改。
- **現況**：activity_update 直接以編號更新，不檢查是否存在或已刪除（會改到已刪除的資料列）；activity_delete 找不到時什麼都不做，但仍回覆「Deleted activity <編號>」。
- **可能後果**：agent 誤以為操作成功（例如編號打錯），使用者得到錯誤的確認。
- **證據**：
    - `Dayflow/Dayflow/Core/AgentAccess/AgentWriteHandlers.swift:151-166`、`:201-212`
    - `Dayflow/Dayflow/Core/Recording/StorageManager+TimelineCards.swift:265-281`（UPDATE 未過濾 is_deleted）
    - `Dayflow/Dayflow/Core/Recording/StorageManager+TimelineCards.swift:187-206`（找不到時直接 return）
- **修正方向**：寫入前查詢未刪除的卡片，找不到時拋出 not_found；更新時加上 is_deleted = 0 條件。

## 3. 分類改名不更新既有卡片（資料一致性，中）

- **規格**：[修改分類](<功能/分類/[功能]修改分類.md>) E-2：改名時一併把既有卡片上的舊分類名稱改為新名稱。
- **現況**：改名只修改分類清單；卡片以名稱保存，舊卡片仍是舊名稱，失去分類顏色，週報與每日目標也對不上新分類。App 介面與 agent 改名都一樣；MCP 工具說明也寫著舊卡片保留原名。
- **可能後果**：使用者改名後，歷史統計被拆成兩個分類，舊卡片看起來像「未分類」。
- **證據**：
    - `Dayflow/Dayflow/Models/TimelineCategory.swift:180-186`（renameCategory 只改清單）
    - `Dayflow/Dayflow/Views/Components/TimelineCardColorPicker.swift:740-778`
    - `Dayflow/Dayflow/Core/AgentAccess/AgentWriteHandlers.swift:104-110`
    - `tools/dayflow-cli/Sources/dayflow/MCPServer.swift:192-202`（update_category 的說明）
- **修正方向**：改名時以舊名稱（不分大小寫）更新所有卡片的分類欄位，並同步修改 MCP 工具說明。
